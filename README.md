# Scratchpad · 草稿编辑器

一个开箱即用的轻量网页文本编辑器：多标签、自动保存（AES-GCM 加密存储）、暂存 / Load all / Burn all、倒计时、阅后即焚（ruin）。

**在线使用（GitHub Pages）**：<https://betteraa.github.io/scratchpad/>

## 功能

- **多标签**：`＋` 新建，双击标签重命名，`✕` 关闭
- **自动保存**：内容加密（AES-GCM）后存浏览器 localStorage，本地非明文
- **暂存**：把当前全部标签加密存入暂存区，随后关闭窗口
- **Load all**：把本地全部暂存一次性加载回来（加载后暂存区自动清空）
- **Burn all**：弹窗确认后清除全部本地暂存，不留痕迹
- **ruin**：清空全部内容并删除所有本地数据（含密钥），随后关闭窗口
- **time**：倒计时（默认 15 分钟，可编辑），运行中醒目显示并可停止；归零后继续负向计时，红色提醒持续到停止，停止后提示完整用时
- **推送 Git**：把当前所有标签的内容按标题提交到当前远端仓库；推送前检查标题，同标题会覆盖远端内容
- **拉取 Git**：按最近 X 天筛选之前推送的内容（默认 1 天），同标题覆盖本地标签，不同标题新建标签
- **试试**：把编辑区内容当 Python 脚本运行，输出显示在底部面板（仅本地版可用）
- **复制**：一键复制当前内容

## 本地版（含 Python 运行能力）

GitHub Pages 是纯静态托管，「试试」按钮会自动禁用。要用 Python 运行能力，clone 本仓库后双击 `启动编辑器.command`（macOS）：

```bash
git clone https://github.com/BetterAA/scratchpad.git
```

- 本地服务只绑定 `127.0.0.1`，以 Chrome 应用模式打开独立窗口（默认约 1/4 屏大小）
- 「试试」在一次性临时目录里执行脚本，15 秒超时保护
- Git 同步仅本地版可用，内容以 UTF-8 文本保存在仓库的 `.scratchpad-content/` 目录中，使用当前仓库的 Git 凭据推送和拉取
- 推送时若远端有新提交，会自动合入后重试；本次推送的同标题使用本地完整内容，保留远端其他标题和代码。其他文件冲突或存在未提交改动时，会保留本地提交并提示原因

## 说明

- 未执行 Git 同步时，草稿数据只存在浏览器 localStorage（密文）；主动推送 Git 后，内容会按普通文本提交到当前远端仓库
- 仓库公开，但各访问者的浏览器存储互相独立，看不到彼此的草稿
