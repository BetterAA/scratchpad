# Git 内容同步设计

## 背景

草稿编辑器目前只把标签内容保存在当前浏览器的加密 `localStorage` 中。用户需要把当前打开的多个编辑框分别保存到远端代码仓库，并能按推送时间取回，继续在本地编辑。

## 目标

- 增加“推送 Git”和“拉取 Git”两个入口。
- 推送当前所有打开标签的标题和内容，标题对应远端内容文件名。
- 推送前提醒用户检查标题；默认标题或空标题必须先处理，避免远端出现无意义文件名。
- 拉取默认筛选最近 1 天内推送的内容，用户可以输入其他天数。
- 拉取到的内容按标题还原为本地标签：同标题覆盖本地内容，不存在的标题新建标签。
- 同标题推送到同一个远端文件，后一次推送覆盖前一次内容。
- GitHub Pages 等没有本地 Git 服务的环境自动禁用 Git 功能。

## 方案

采用现有本地 Python 服务作为 Git 操作边界。浏览器不保存 Token，也不直接调用 GitHub API；本地服务使用当前仓库已有的 Git 凭据和 remote 配置完成同步。

远端内容统一保存到仓库根目录的 `.scratchpad-content/`，每个标签对应一个 UTF-8 文本文件：

```text
.scratchpad-content/<标题>.txt
```

标题会经过服务端路径校验：去除首尾空格后不能为空，不能是 `.` 或 `..`，不能包含 `/`、反斜杠、空字节或控制字符。这样标题仍然可读，同时不会越出同步目录。文件扩展名固定追加 `.txt`，标题本身可以包含句点。

一次推送处理所有打开标签并创建一个提交。若当前打开标签存在同名标题，按标签顺序由后出现的内容覆盖前一个内容，保持“相同标题覆盖”的规则。推送只暂存 `.scratchpad-content/` 中本次涉及的文件，不会把用户其他未提交的代码改动带入提交；没有内容变化时直接返回无变化结果。

拉取先执行 `git pull --ff-only`，确保当前工作树能安全读取远端分支。服务端列出 `.scratchpad-content/*.txt`，读取每个文件最近一次提交时间，只返回最近 X 天内变更的文件，默认 X 为 1。浏览器收到列表后按标题合并到当前 `state.tabs`，同标题标签全部更新为远端内容，没有匹配项的内容追加为新标签。

## 接口

### `GET /git/status`

返回当前仓库是否可以执行 Git 同步、当前分支和 remote 是否存在。静态页面收到非 2xx 或请求失败时将两个 Git 按钮置灰。

### `POST /git/push`

请求体：

```json
{
  "items": [
    {"title": "工作记录", "content": "..."}
  ]
}
```

服务端写入文件、创建提交并推送当前分支，返回提交短哈希、推送文件数和无变化状态。仓库不存在、分支无 upstream、认证失败或推送冲突都返回可展示的错误信息。

### `POST /git/pull`

请求体：`{"days": 1}`。服务端将天数限制在 1 到 3650，执行快进拉取后返回匹配文件的标题、内容和最近提交时间。工作树有阻止快进拉取的本地改动时返回错误，不覆盖用户尚未提交的代码文件。

## 界面与交互

- 顶部工具栏增加 `推送 Git`、`拉取 Git` 两个按钮。
- 推送弹窗列出当前所有标签标题，并说明同标题会覆盖远端内容；确认前再次提示标题必须已编辑。
- 若发现默认标题（如“草稿 1”）或空标题，不发起请求，在消息面板列出需要重命名的标签。
- 拉取弹窗提供天数输入框，默认值为 1，并说明同标题内容会覆盖本地标签。
- 操作过程中按钮禁用，消息面板展示进行中、成功数量、覆盖数量和错误原因。
- 本地服务不可用时，按钮保持禁用并显示“仅本地版可用”。

## 错误处理

- 服务端所有 Git 命令使用超时和非交互凭据模式，避免认证弹窗让页面永久等待。
- Git 命令失败时返回 stderr 的可读摘要，浏览器不把错误静默吞掉。
- 拉取响应中重复标题只保留服务端文件列表中的唯一文件；本地重复标题全部同步为同一份内容。
- 空仓库或没有匹配日期的远端内容返回成功但数量为零，页面显示明确提示。

## 测试策略

- 用 Python `unittest` 测试标题路径校验、Git 命令参数构造、推送请求 JSON 校验和按提交时间筛选逻辑，Git 命令通过临时仓库和可替换的命令执行器隔离。
- 用现有 Node 测试继续覆盖前端无 DOM 的逻辑；新增标题校验和拉取合并逻辑应提取为可测试函数。
- 在本地浏览器验证：无本地服务时按钮禁用；推送标题提醒；多个标签推送；同标题覆盖；不同天数拉取；拉取覆盖同标题本地内容并追加新标签。
