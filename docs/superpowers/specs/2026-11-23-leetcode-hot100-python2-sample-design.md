# 力扣 Hot 100 Python 2 复习手册设计

## 目标

在 `/Users/andy/openclaw-AA/codinglist` 生成一份独立 Markdown 复习手册，覆盖力扣官方 Hot 100 全部 100 题，使用已确认的先思考、后展开答案的刷题版式和 Python 2.7 代码风格。

## 范围

- 题目来源：力扣官方[热题 100 学习计划](https://leetcode.cn/studyplan/top-100-liked/)。
- 覆盖范围：官方题单当前顺序的完整 100 题，按哈希、双指针、滑动窗口、子串、普通数组、矩阵、链表、二叉树、图论、回溯、二分查找、栈、堆、贪心算法、动态规划、多维动态规划、技巧 17 个分类排列。
- 每题按“题号与元信息、题目描述、输入输出示例、可填写的思考区、折叠答案”排列；折叠答案包含解题思路、复杂度、易错点和 Python 2.7 兼容代码模板。
- 代码模板只使用 Python 2.7 语法；不使用类型注解、f-string、`dataclass`、`pathlib` 等 Python 3 特性。
- 文档开头提供使用说明、难度说明和进度复习方式，并说明 HTML `details` 不支持时仍可直接阅读答案。

## 单题结构

每道题按以下顺序组织：

1. 复选框、题号、题名和难度；
2. 官方题目链接与核心模式；
3. 用自己的话概括的题目描述；
4. 至少一组输入输出示例和必要解释；
5. 可填写的“我的思考区”，包含解法、状态或不变量、边界情况、复杂度预估；
6. 默认折叠的解题思路、时间复杂度、空间复杂度、常见错误和 Python 2.7 `class Solution` 或题目要求的设计类名模板。

模板保持短小，优先展示该题最值得记忆的算法骨架。涉及输入输出的题目只保留力扣方法签名，不添加本地交互代码。思考区先于答案，帮助用户在展开折叠内容前独立建模。

## 验收标准

- 恰好包含完整 100 道题，题号、题名、分类顺序和官方题单一致；
- 每题都有题面、输入输出示例、思考区和一个闭合的 `<details>` 折叠答案，链接指向对应的 `leetcode.cn/problems/<slug>/` 页面；
- 每个折叠答案包含解题思路、复杂度、易错点和一个 Python 代码块；
- 代码块可被 Python 2.7 解析，且没有明显的 Python 3 专属语法；
- Markdown 标题层级和复选框可正常阅读；
- 文件落在用户指定目录 `/Users/andy/openclaw-AA/codinglist`。
